# Casio CZ-101 — VST3 / Standalone (versões)

Instaladores do **Casio CZ-101**, uma emulação do sintetizador de distorção de fase da Casio.

**Site:** https://helicleiton.github.io/casio-cz101-releases/ · **Tocar no navegador:** https://helicleiton.github.io/casio-cz101-releases/play/

## Instalar

1. Abra a [última versão](https://github.com/helicleiton/casio-cz101-releases/releases/latest).
2. Baixe `CasioCZ101-Setup-x.y.z.exe` e execute (não precisa de administrador).

O instalador coloca o app **Standalone** e o plugin **VST3**. O VST3 fica em
`%LOCALAPPDATA%\Programs\Common\VST3`. Se a sua DAW não encontrar o plugin, adicione essa pasta
na lista de pastas VST3 dela.

Windows 10/11, 64 bits.

## Atualizações

São automáticas. O app e o plugin baixam as versões novas em segundo plano, sem fechar.
A versão nova passa a valer na próxima vez que o app ou a DAW abrir.
